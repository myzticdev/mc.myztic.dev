NoChatPopup

A lightweight plugin with one job: hide the “Chat messages can't be verified” popup when players join.

OverviewInstallationFiles & downloads

A quieter welcome.

NoChatPopup targets the unverified-chat warning shown on join. It leaves chat messages, formatting, signatures, and reporting unchanged.

  • No required plugins.
  • No commands, permissions, or plugin-specific configuration.
  • No changes to authentication or server.properties.

Releases are free. Quick updates for new Paper versions are the goal, with no paid early-access tier.

Hiding the popup does not make unsigned chat verified.

Installation

  1. Download NoChatPopup-1.0.0.jar.
  2. Place the JAR in your server's plugins/ directory.
  3. Restart the server fully.

Requires Paper 26.3 and Java 25 or newer. Use a full restart, not /reload or a plugin hot-loader.

To update, stop the server, replace the old JAR, and start it again. To uninstall, stop the server and remove the JAR.

Metrics

Standard bStats usage metrics are included, with no custom charts. To opt out, set enabled: false in plugins/bStats/config.yml and restart. This shared setting also affects other plugins using that configuration.
