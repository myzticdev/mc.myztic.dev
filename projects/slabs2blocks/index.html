Slabs2Blocks

Craft two matching slabs back into one full block.

The recipe

Place two identical slabs side by side in your inventory grid or a crafting table to recover one matching block. Two oak slabs make oak planks, two stone brick slabs make stone bricks, and waxed copper keeps its wax and oxidation stage.

Slabs to blocks recipe
InputOutput
2 matching slabs (side by side)1 matching block

The slabs must match exactly. Vertical pairs still work for vanilla recipes such as chiseled stone bricks and bamboo mosaic. Slabs with several vanilla source blocks return the plain material, so quartz slabs give a quartz block. The pack covers slabs with a standard vanilla crafting recipe in your version. Recipes are not added to the recipe book, so craft them by hand. On Java 1.21.11, the 1.20.2–26.3 ZIP adds 61 recipes.

Installation

  1. Download the ZIP for your Minecraft Java version.
  2. Place it in your world's datapacks/ folder. Install only one variant.
  3. Reopen the world or run /reload.
  4. Check it loaded with /datapack list enabled.

Using the all-versions bundle? Extract it first, then install only the inner ZIP that matches your version. On a server, only the server needs the datapack. Bedrock Edition is not supported. Put one slab in each of two neighboring slots on the same row, then craft it manually in the grid.
