Flesh2Leather

Turn rotten flesh into leather.
Just add fuel.

Download ↗ Source ↗

The recipe

Cook 1 rotten flesh to get 1 leather. Use a furnace, or a smoker on Java 1.14 and later.

Cooking time and experience by workstation
WorkstationTimeXP
Furnace10 seconds0.35
Smoker5 seconds0.35

Uses recipes only. No resource pack or background functions required.

Installation

  1. Download the ZIP for your Minecraft Java version.
  2. Place it in your world's datapacks/ folder.
  3. Reopen the world or run /reload.
  4. Check it loaded with /datapack list enabled.

Using the all-versions bundle? Extract it first, then install only the inner ZIP that matches your version.
