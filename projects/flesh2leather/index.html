Install

Drop it in and reload.

  1. Download the ZIP matching your Minecraft Java version from GitHub Releases.
  2. Place that ZIP in your world's datapacks/ folder.
  3. Reopen the world or run /reload.
  4. Check /datapack list enabled, then cook Rotten Flesh with fuel.

Install only one version-specific ZIP. If you use the all-versions bundle, extract it first and choose the correct inner ZIP.
