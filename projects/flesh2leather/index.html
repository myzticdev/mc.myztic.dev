Overview

Simple by design.

Flesh2Leather adds one practical survival recipe: cook Rotten Flesh into Leather. It stays small, predictable, and easy to maintain across Minecraft versions.

Install

Drop it in and reload.

  1. Download the ZIP matching your Minecraft Java version.
  2. Place it in the world's datapacks/ folder.
  3. Reopen the world or run /reload.
  4. Verify with /datapack list enabled.
  5. Cook Rotten Flesh with fuel.

Install only one version-specific ZIP. If you use the all-versions bundle, extract it first and choose the correct inner ZIP.
